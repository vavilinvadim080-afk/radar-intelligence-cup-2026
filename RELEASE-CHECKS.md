# Проверка комплекта для сдачи

Обновлено: 2026-11-12. Приложение проверялось в отдельной временной копии. Рабочая вкладка пользователя и её состояние не сбрасывались.

- Python 3.12: полный прогон `python -B -m pytest -q -p no:cacheprovider tests mvp-v13-adapted/tests` прошёл: 809 тестов, 93 subtests. 10 опциональных проверок пропущены по условиям окружения. Два предупреждения: устаревающий интерфейс TestClient и намеренно отклонённый тестовый pickle-кэш. Чистая установка зависимостей с нуля в этом проходе не выполнялась.
- Отдельно прошли 26 проверок CLI, входа и API. Флаг `--access-url` показывает существующую локальную ссылку, не запускает сервер и не создаёт новый секрет. Ключ из фрагмента адреса удаляется после открытия и сохраняется в sessionStorage.
- Сохранённые предсказания v5c независимо пересчитаны без запуска моделей: `python -B scripts/check_saved_metrics_v5c.py`. Проверены опубликованные исходники, входы, эталоны и арифметика. Нейросетевые веса и приватные записи подготовки синтетики этот пересчёт не проверяет.
- В браузере 1440×1000 открылись оба режима приложения: восемь тем потребностей, четыре сообщения в истории выбранной темы, воспроизведение инцидента. Ошибок JavaScript нет. Вкладки качества презентации показывают по шесть столбцов из фактического отчёта v5c.
- Новый ролик: 205,866 секунды, 1920×1080, 30 кадров/с. Технически проверены полное декодирование, субтитры, громкость и свежее распознавание речи. Из готового MP4 просмотрены состояния карточки и последствия кликов. Естественность дикторской речи ещё требует прослушивания пользователем.
- Основное решение: 14907 символов Markdown, 14751 символ извлечённого PDF, шесть страниц. Лимит 15000 соблюдён. Пункт 5 находится в отдельном Markdown и вспомогательном PDF.
- Презентация PDF: 13 страниц. Текст всех четырёх проверенных PDF находится в границах страниц. HTML сохраняет интерактивные действия, PDF фиксирует выбранные состояния.
- Проверены файлы комплекта, все локальные Git-объекты и отправляемый ZIP: типовые ключи провайдеров, приватные ключи, токены, адреса с паролями и совпадения с локальными секретами. Рабочих секретов не обнаружено. Найденные фиктивные ключи и адреса относятся к тестам. Веса, рабочие базы, окружения и реальные файлы секретов исключены из архива; в runtime опубликованы только четыре MANIFEST.json с ревизиями и хэшами моделей.
- Контрольные суммы опубликованных файлов находятся в SHA256SUMS. В ZIP включаются только файлы Git, без содержимого локальных игнорируемых каталогов.

Пределы результата: данные синтетические. Реальные обращения, внутренние модели и инфраструктура заказчика, внешняя доставка и фактический денежный эффект не проверены. Кандидат v5c не прошёл критерии выпуска; цель 80% для каждого показателя не объявлена достигнутой. Потоковый эксперимент отличается от пакетной проверки истории и требует собственной оценки. По умолчанию запускаются демонстрационные правила и шаблоны. Подробности в docs/QUALITY.md.
