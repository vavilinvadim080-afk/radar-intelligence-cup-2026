# Порядок просмотра

1. `../video/index.html`: обзор2:44.
2. `radar.html`: интерактивная презентация для жюри.
3. `../README.md`: запуск приложения и карта исходников.

Откройте HTML в обычном браузере. Стрелки переключают слайды и действия внутри раздела. Esc возвращает к карте; следующий переход после финала также открывает карту. Кнопки внутри слайда раскрывают инструменты, сценарии экономики и подробности качества. Рекомендуется полноэкранный просмотр.

`radar.pdf` содержит13 статических страниц. Он пригоден для быстрого чтения, но не сохраняет все действия HTML. `radar-notes.html` содержит заметки докладчика, доступные по кнопке «Заметки» или N.

Для демо запустите `python run.py` из корня. Презентация самодостаточна и открывается без запуска приложения.
