# Приложение Радар

Запуск из корня всего репозитория: `python run.py`. Установка и порядок просмотра описаны в [основном README](../README.md).

`app/` содержит сервер и интерфейс, `radar/` содержит статистический конвейер, `tests/` содержит проверки, `shared/` хранит синтетические измерения прежних прогонов. `eval/` содержит вспомогательные скрипты их воспроизведения.

Базы, HMAC-ключи, подписи и кэши создаются локально и не входят в Git. Демонстрационные записи в `demo/replay.json` относятся к синтетическому сценарию. Подробности и границы приведены в [документации](../docs/ARCHITECTURE.md).
