# Запуск и интеграции

## Локальное демо

Из корня: `python run.py --check`, затем `python run.py`. Сначала установите `requirements.txt` в своё окружение Python3.12. По умолчанию используется порт8799 и доступ только с этого компьютера. Для другого порта: `python run.py --port 8801`.

`python run.py --no-open` печатает локальный адрес с токеном, который можно открыть вручную. Этот адрес предоставляет доступ к кнопкам демо, поэтому его не следует помещать в публичные отчёты. Токены и ключи создаются на компьютере пользователя с ограниченными правами файла. Записи, аудит и кэши появляются локально и исключены из Git.

Демо-данные вымышлены. В потребностях нажмите «Загрузить пример». В инцидентах выберите готовую сцену. Первое построение статистического сценария занимает время; дальнейшие открытия используют локальный кэш. Записанный пример ответов агента при первом запуске получает локальную HMAC-подпись. Ключ другой установки не передаётся.

## Внутренний контур компании

Настройки приведены в `.env.example`; этот файл служит справкой, автоматической загрузки `.env` нет. Администратор задаёт переменные окружения:

| Переменная | Назначение |
|---|---|
| `RADAR_NEEDS_MODE=internal` | Выбрать адаптер внутреннего анализа |
| `RADAR_MODEL_URL` | Согласованный адрес совместимого API |
| `RADAR_MODEL_IPS` | Разрешённые IP назначения |
| `RADAR_MODEL_NAME` | Фактическое имя текстовой модели |
| `RADAR_ASR_NAME`, `RADAR_VL_NAME` | Имена моделей распознавания |
| `RADAR_MODEL_TOKEN` | Секрет для доступа, если он требуется |

Названия Qwen3.8, Qwen-ASR и Qwen-VL взяты из условия. Наличие моделей у компании не доказывает совместимость конкретного API. Форматы, адреса, квоты и права согласуются перед подключением. Внешние LLM API в целевом решении не используются.

## Локальная семантика v5b

Это опциональный исследовательский режим, он не нужен для просмотра демо. Исходники и зафиксированные результаты сохранены; нейросетевые веса в Git не входят. Статические `runtime/models/*/MANIFEST.json` закрепляют ревизии, размеры и SHA256.

Для воспроизведения можно отдельно установить `requirements-models.txt`, затем явно запустить `python scripts/download_models.py qwen nli`. Эта команда скачивает публичные локальные модели и требует нескольких гигабайт диска. Она не вызывается при обычном запуске. Для сравнения с E5 укажите также `e5`.

В экспериментальном запуске задаются `RADAR_NEEDS_MODE=semantic-v5b`, `RADAR_ALLOW_EXPERIMENTAL=1`, `RADAR_SEMANTIC_PYTHON` с путём к Python окружения моделей. Launcher подставляет текущий Python, если отдельный путь не задан. Опция допуска обозначает эксперимент; проверка независимого качества не пройдена, автоматический промышленный выпуск ею не подтверждается. Модели запускаются последовательно.

## Просмотр сохранённой оценки

Для проверки арифметики качества без модели: `python scripts/check_saved_metrics.py`. Отчёт использует сохранённые предсказания и опубликованную синтетическую разметку. Получение новых нейросетевых предсказаний и приёмка на данных заказчика являются отдельными действиями.
