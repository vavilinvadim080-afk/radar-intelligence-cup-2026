# Проверенные результаты

Новый контроль v5c: Qwen v5b и Qwen с проверкой пар оценены на одном новом синтетическом наборе. Параметры и код зафиксированы до открытия контрольных входов; эталон открыт только после сохранения полных предсказаний. Источник: `data/quality-v5c.json` и `reports/quality-v5c/`. Отдельный метод перегруппировывает накопленную историю, включая ранние сообщения; время онлайн-обработки этим опытом не измерялось.

| Метрика кандидата | Знаменатель | Результат |
|---|---|---|
| Accuracy (верные типы) | 184 сообщений | 153/184 = 83,2% |
| Precision (точность группировки) | TP + FP | 132/(132+128) = 50,8% |
| Recall (полнота группировки) | 240 истинных пар | 132/240 = 55,0% |
| Precision обычного автоответа | TP + FP | 7/(7+3) = 70,0% |
| Recall обычного автоответа | 30 допустимых из120 | 7/30 = 23,3% |

Обычный автоответ и сообщение об исправлении оцениваются отдельно. Автоматический выпуск отключён: цель80% для каждого показателя и отсутствие ложных ответов являются разными проверками. Текущий результат не выдаётся за качество на внутренних обращениях заказчика. Для независимого пересчёта без моделей: `python -B scripts/check_saved_metrics_v5c.py`. Проверяются сохранённые предсказания и опубликованные исходники; нейросетевые веса и приватные записи подготовки синтетики эта команда не проверяет.

## Интерактивный эксперимент

`RADAR_NEEDS_MODE=semantic-v5c` вместе с `RADAR_ALLOW_EXPERIMENTAL=1` включает отдельный адаптер. Нужны локальные веса и дополнительные зависимости. Он извлекает до8 примеров из ограниченного каталога, запускает модели последовательно и сообщает об отсутствии доказательств. Это потоковый прототип с другой процедурой, поэтому проценты группировки всей истории не приписываются ему. Промышленная задержка и качество этого режима отдельно не измерены. Если допуск автоответа не пройден, адаптер возвращает обращение оператору до загрузки модели. Приложение по умолчанию остаётся демонстрацией на синтетике.

## Предыдущий контроль v5b

Источник: `data/quality-v5b.json`. Зафиксированный локальный метод использует Qwen3-Embedding-0.6B с1024 координатами, классификатор типа и проверку пар с NLI-признаками. Выбор сделан до независимого контрольного прогона. Входы, эталоны, протокол и lock-файл опубликованы в `evaluation/v5b/`; предсказания и снимок конфигурации находятся в `reports/quality-v5b/`.

| Задача | Знаменатель | Результат |
|---|---|---|
| Accuracy типа | 116 уникальных обращений | 101/116=87,1% |
| Precision группировки | 115 предсказанных связей | 82/(82+33)=71,3% |
| Recall группировки | 144 правильные связи | 82/(82+62)=56,9% |
| Precision обычного автоответа | 22 подготовленных ответа | 15/(15+7)=68,2% |
| Recall обычного автоответа | 20 допустимых ответов из80 случаев | 15/(15+5)=75% |

TP: правильный положительный выбор. FP: ошибочный положительный выбор. FN: пропуск. Precision=TP/(TP+FP), Recall=TP/(TP+FN). Accuracy типа считает верно определённый класс сообщения. Попарные метрики оценивают объединение сообщений, а полезность продуктовой карточки проверяется отдельно.

Автоматический выпуск смыслового отбора и автоответа не разрешён. На том же контроле частотный вариант дал Precision50%/Recall2,1% группировки, E5 с проверкой пар дал23,6%/44,4%. Это сравнение конкретных локальных конвейеров на одной синтетике; оно не определяет лучшую модель для любых задач.

Исходный статистический детектор имеет отдельный сохранённый результат на синтетике: Precision51/85=60%, Recall47/69≈68%, медиана99минут до карточки. Эти значения относятся к всплескам и не заменяют оценку потребностей. Встроенные в старый интерфейс графики сохраняют подписи своего эксперимента.

## Границы доказательств

Реальные обращения и внутренние модели компании при подготовке недоступны. Разметка синтетики не является экспертной разметкой заказчика. Старый контроль раскрыт после фиксации предсказаний; повторная настройка по нему не считается новым независимым испытанием.

Функциональные проверки подтверждают работу отдельных механизмов, API, ограничений, пагинации и расчётов. Они не измеряют новое семантическое качество. Новый контроль v5c приведён выше; его знаменатели отличаются от исторического v5b.

Экономика берётся из `data/economics.json`: 2880часов/год ёмкости команды, 2,304млн₽ стоимости времени и 973333,33₽ предела первоначальных вложений за три года при базовых допущениях. Автоответ к эффекту повторно не прибавлен. 1200/1800/3600 обращений в рабочий день являются сценарной ёмкостью40×6×60/(12/8/4), а фактический поток неизвестен.
